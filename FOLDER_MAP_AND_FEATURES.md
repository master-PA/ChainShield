# ChainShield Sentinel — Project Folder Map & Feature Implementation Analysis

> **Platform Overview:** ChainShield Sentinel is a Pre-Transaction Web3 Security Platform that evaluates decentralized applications, smart contract calldata, and unsolicited communications *before* a user connects their wallet or confirms a transaction. It provides an explainable 0–100 risk score, plain-language intent decoding, simulation preview, claim-vs-reality verification, and tamper-evident cryptographic evidence anchored on the Ethereum Sepolia testnet.

### Core Security Libraries & Decoders (`src/lib/`)

| File Path | Purpose & Responsibilities | Exported Functions / Implementation Detail |
|---|---|---|
| `src/lib/canonicalJson.ts` | **Deterministic canonical serialization and cryptographic SHA-256 hashing.** Adheres to RFC-8785 and Python `json.dumps(sort_keys=True, separators=(',', ':'))`. Contains a full pure-JS SHA-256 fallback implementation (`sha256Pure`) ensuring synchronous and asynchronous hashing without external library dependencies. | `canonicalizeJson()`, `computeSha256()`, `computeSha256Sync()`, `buildCanonicalScanPayload()`, `hashCanonicalScanPayload()`, `verifyScanEvidence()`, `verifyScanEvidenceSync()` |
| `src/lib/blockchainEvidence.ts` | **Ethers.js Sepolia client for live on-chain queries and wallet anchoring.** Interacts with the deployed `EvidenceRegistry` contract via JSON-RPC. Parses RPC errors (`formatRpcError`) into friendly diagnostics (user rejection, rate limit, duplicate ID, insufficient funds). Handles Web3 wallet network switching to Sepolia (Chain ID 11155111). | `getBlockchainConfig()`, `queryOnChainEvidence()`, `anchorEvidenceWithWallet()`, `formatRpcError()`, `SEPOLIA_CHAIN_ID` |
| `src/lib/contractScorer.ts` | **Deterministic contract risk scorer with non-double-counting policy.** Calculates an overall risk score (0–100) using a diminishing returns multiplier (100% for 1st finding, 50% for 2nd, 25% for 3rd, 0% thereafter). Evaluates unverified contracts by assigning 55 points (uncertainty/lack of auditability rather than confirmed exploit) and proxies with partial/missing implementation by 20 points. Formulates actionable security recommendations. | `calculateContractRiskScore()`, `getContractRiskLevel()`, `ContractScorerResult` |
| `src/lib/txDecoder.ts` | **Pure EVM calldata parser without ABI files.** Decodes function selectors: `0x095ea7b3` (`approve`), `0xa2205344` (`setApprovalForAll`), `0xa9059cbb` (`transfer`), `0x23b87266` (`transferFrom`), and `0xd505accf` (`permit`). Checks for unlimited allowances (`>= 2^255`) and produces plain-language descriptions in English, Hinglish, and Simple terms. | `decodeTransactionCalldata()`, `cleanHex()`, `parseAddressFrom32Bytes()` |
| `src/lib/claimChecker.ts` | **Claim-vs-Reality intent mismatch detector.** Compares visible webpage claims (e.g., "Claim Free NFT", "Airdrop", "Verify Wallet") against decoded calldata action types. Flags mismatches where "Claim" actually triggers `setApprovalForAll` (Blanket NFT drain) or unlimited `approve`. Calculates a mismatch score (0–100). | `evaluateClaimVsReality()` |
| `src/lib/rulesEngine.ts` | **Deterministic rule-based heuristics engine.** Evaluates domain hostname: Levenshtein distance typosquatting against known dApps, Punycode/Cyrillic homoglyph detection, disposable high-risk TLD penalties (`.xyz`, `.top`, `.click`), unsolicited link source penalties (Telegram DM: +15, Discord: +10), and drainer keyword signatures. | `evaluateTargetRules()`, `extractHostname()`, `levenshteinDistance()` |
| `src/lib/mlEngine.ts` | **Supervised machine learning risk aggregator.** Combines deterministic rules score with simulated Random Forest supervised probability weights (`0.6 * rules + 0.4 * ML`). Enforces hard overrides: confirmed threat feed or drainer matches automatically force HIGH or CRITICAL risk (>= 80). Formulates actionable recommendation (`AVOID`, `PROCEED_WITH_CAUTION`, `SAFE_TO_PROCEED`). | `computeCombinedRisk()`, `getRiskLevel()` |
| `src/lib/messageClassifier.ts` | **Multilingual phishing message analyzer.** Detects language (English vs. Hinglish), extracts embedded URLs, and scores signals for seed phrase traps (soliciting 12/24 words: +95 pts), artificial urgency manipulation (+20 pts), authority impersonation (MetaMask/Collab.Land: +25 pts), and fake airdrop/investment promises. | `classifyMessage()` |
| `src/lib/chatbotEngine.ts` | **Deterministic support assistant without LLM hallucination.** Tokenizes user queries and computes Jaccard/cosine similarity against a 20+ item knowledge base. Extracts Ethereum addresses, URLs, and transaction hashes to offer instant navigation shortcuts. Supports English and Hinglish responses. | `answerSupportQuery()`, `tokenize()`, `cosineJaccardSimilarity()` |
| `src/lib/scanStorage.ts` | **Versioned localStorage persistence engine.** Implements a `MemoryStorage` polyfill for SSR/tests. | `src/lib/formatters.ts` | **Visual presentation and styling helpers.** Formats addresses (`0x1234...5678`), transaction hashes, relative timestamps (`5m ago`), and returns Tailwind CSS classes for LOW (emerald), CAUTION (amber), HIGH (orange), and CRITICAL (rose) risk levels. | `shortenAddress()`, `shortenHash()`, `formatTimeAgo()`, `getRiskColorClass()` |

### Static AST Contract Analyzer (`src/lib/contractAnalyzer/`)

| File Path | Purpose & Responsibilities | Exported Functions / Implementation Detail |
|---|---|---|
| `contractAnalyzer/astParser.ts` | **Solidity Abstract Syntax Tree (AST) parser.** Wraps `@solidity-parser/parser` to transform multi-file Solidity source code into navigable AST objects. Handles multi-contract source bundles, pragma directives, import directives, interfaces, and library declarations with defensive error tolerance. | `parseSoliditySource()`, `parseMultiFileSource()` |
| `contractAnalyzer/types.ts` | **Type definitions for smart contract static security inspection.** Defines data models for AST nodes, functions, state variables, modifiers, security findings (`ContractFinding`), severity levels (`CRITICAL`, `HIGH`, `MEDIUM`, `LOW`, `INFORMATIONAL`), and rule signatures. | `ContractFinding`, `ContractAST`, `FunctionAST`, `ContractAnalyzerRule`, `AnalysisContext` |
| `contractAnalyzer/analyzer.ts` | **Master AST rule orchestrator.** Coordinates the execution of all registered deterministic security rules across parsed AST representations. Normalizes rule findings, deduplicates by line/signature, and constructs the aggregate AST finding array. | `analyzeContractSource()`, `registerRule()`, `ALL_RULES` |
| `contractAnalyzer/rules/unrestrictedMint.ts` | **Arbitrary / Unauthenticated Mint Rule.** Inspects function definitions matching token creation names (`mint`, `_mint`, `mintTo`). Verifies presence of access-control modifiers (`onlyOwner`, `hasRole`, `auth`) or `require(msg.sender == owner)`. Flags critical vulnerabilities if external callers can supply an arbitrary destination address. | `unrestrictedMintRule` |
| `contractAnalyzer/rules/unprotectedOwnership.ts` | **Unprotected Ownership Transfer Rule.** Detects public/external functions that modify state variables named `owner`, `admin`, or `governance` without checking caller authorization. Flags instances where anyone can seize administrative control of the contract. | `unprotectedOwnershipRule` |
| `contractAnalyzer/rules/dangerousCalls.ts` | **Arbitrary Call & Delegatecall Rule.** Identifies unchecked low-level `.call()`, `.delegatecall()`, or inline assembly calls with user-supplied target addresses or data. Flags potential reentrancy, malicious library hijacking, or proxy takeover vectors. | `dangerousCallsRule` |
| `contractAnalyzer/rules/authWeaknesses.ts` | **Authentication Weaknesses Rule.** Flags the usage of `tx.origin` in conditional authorization checks (`require(tx.origin == owner)`), warning against phishing relay attacks. Identifies missing or empty modifier implementations. | `authWeaknessesRule` |
| `contractAnalyzer/rules/destructiveOps.ts` | **Destructive Operations & Drain Rule.** Inspects bytecode and source for `selfdestruct` / `suicide` opcodes and unauthenticated balance-draining transfer methods (`payable(msg.sender).transfer(address(this).balance)`). | `destructiveOpsRule` |
| `contractAnalyzer/rules/proxyAwareness.ts` | **Proxy Architecture & Storage Slot Rule.** Detects EIP-1967 proxy structures, OpenZeppelin upgradeable contracts, beacon proxies, and implementation storage slots (`0x360894...`). Identifies missing implementation source or proxy initialization vulnerabilities. | `proxyAwarenessRule` |
