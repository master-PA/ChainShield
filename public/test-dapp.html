How Pre-Sign Interception Testing Works:
  1. Click any test button below. The dApp triggers an EIP-1193 wallet request (e.g. eth_sendTransaction).
  2. ChainShield Sentinel intercepts the request in the browser before the wallet confirmation window appears.
  3. An isolated Closed Shadow DOM warning modal pops up displaying decoded intent, risk score, and claim-vs-reality mismatch.
  4. Click "Cancel & Block Request": The request is aborted with EIP-1193 code 4001. The wallet never receives the request.
  5. Click "Proceed to Wallet": The request forwards untouched to your wallet with the exact original parameters.
Note: Testing does NOT broadcast transactions or spend any funds. A built-in mock wallet runner is active if no browser wallet extension is installed.
