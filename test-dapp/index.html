How Pre-Sign Interception Testing Works:
  1. Click any test button below. The dApp triggers an EIP-1193 wallet request (e.g. eth_sendTransaction).
  2. ChainShield Sentinel intercepts the request in the browser before MetaMask or any wallet prompt appears.
  3. An isolated Closed Shadow DOM warning modal pops up displaying decoded intent, risk score, and claim-vs-reality mismatch.
  4. Click "Cancel & Block Request": The request is aborted with EIP-1193 code 4001. MetaMask is never prompted.
  5. Click "Proceed to Wallet": The request forwards with exact original parameters and causes MetaMask to open its confirmation prompt.
Note: Testing does NOT broadcast transactions or spend funds. A built-in mock wallet runner is active if no browser wallet extension is installed.
